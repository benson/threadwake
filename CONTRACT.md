# Threadwake module contract

Original standalone game. Plain ES modules + Vite. World coordinates in pixels; arena 1200 × 800. Authoritative simulation shared by browser solo and Cloudflare room, fixed 30 Hz. Render 640 × 360, camera follows local player, all sprites snapped to integer pixels. Sprite poses stepped 12 fps. Separate `/lab.html` workshop.

## Simulation (src/sim.js, src/config.js)

Exports `createGame(seed=1)`, `addPlayer(state,id,name='Weaver',traits={})`, `removePlayer(state,id)`, `step(state,inputs,dt=1/30)`, `chooseUpgrade(state,id,upgradeId)`, `startGame(state)`, `snapshot(state)` (plain JSON, excludes internal history), `UPGRADES`.
`inputs` object keyed player ID, each `{x,y,cast}`. Normalize movement; cast rising edge triggers echo.
State: `{version:1,seed,tick,time,phase:'lobby'|'playing'|'draft'|'won'|'lost',wave,waveTime,players:[],enemies:[],shots:[],echoes:[],flowers:[],effects:[],choices:{},kills, caught}`.
Player: `{id,name,x,y,vx,vy,hp,maxHp,dead,color,face,castCooldown,hit,upgrades:[],kills}`. `color` 0..3. Coordinates bounded. Upgrades are IDs; choices[id] array of three IDs in draft. UPGRADES array `{id,name,description,icon}`.
Enemy: `{id,type:'mite'|'moth'|'thorn'|'warden',x,y,hp,maxHp,r,hit,phase,face}`. Shot: `{id,x,y,vx,vy,hostile,r,color}`. Echo: `{id,owner,x,y,life,maxLife}`. Flower: `{id,x,y,charge,life}`. Effect: `{id,type:'hit'|'death'|'catch'|'cast'|'bloom',x,y,life,maxLife,color}`. Additional fields allowed. All entity IDs unique.
Each wave ends in synchronized draft. startGame only from lobby or end resets run preserving players. Late join permitted. Downed players revived by nearby ally, or next wave. Whole team down = lost. Final wave boss = won. Bounded entity counts and input validation.

## Rendering (src/render.js, src/art.js, src/animation.js)

Exports `createRenderer(canvas)` returning `{draw(state,localId,time,options={}),screenToWorld(x,y),camera}`. Options `{reducedMotion,shake,lab}`; background title uses demo state or lobby. Draw the whole world including atmosphere, environment, sprites, projectiles, threads, blooms; HUD is DOM by main.
Expose reusable `drawActor(ctx,actor,time,settings={})` and animation parameter defaults from animation.js for workshop. Pure sprite authoring with hand-designed pixel clusters, palette, shade ramps. No external unlicensed assets. Shared renderer and art used by workshop and game.

## Networking (src/net.js, worker/)

Export `connectRoom({room,name,onState,onStatus,onIdentity})` async returns `{sendInput(input),start(),choose(id),close()}`. onIdentity receives `{id,room}`. onStatus string connecting/connected/reconnecting/closed/error. onState full serialized state. Room secure random 8+ chars generated by main. URL `?room=...`. Server authority, validation, room cap 4, reconnect opaque token sessionStorage, server sends 15Hz snapshots and simulates at 30Hz. Worker imports shared sim. No client may send world state.

## Main (src/main.js, style.css, index.html)

Parent owns browser loop, menus, HUD, keyboard/mouse/gamepad inputs, audio, workshop UI, progression, end-to-end validation and deployment coordination. Agents must stay within assigned files. All source committed; output/ ignored. Do not modify sibling projects.
